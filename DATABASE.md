# Database

SQLite migration 1: immutable `events` (UUID, record ID, type, parent revision IDs, actor, device, timestamp, payload, deletion flag), `meta` (schema/settings), `sync_queue` (pending UUIDs), `sync_state` (cursor), and indexes. Normalized entities are represented by independently versioned records: household (exactly two users), account, transaction, bill, debt, investment, goal, budget, recurring rule, category, exchange rate, attachment. Transaction discriminators replace redundant income/expense/transfer/payment tables. Relationships use stable UUIDs; commands validate currencies and references. Account balances and payment totals are derived, never overwritten. Audit is the complete event history. Heads are derived from parent edges; more than one head is a conflict.

Amounts are safe integer minor units, rates are integer rational units. Each posting freezes its base currency conversion ratio. Savings are accounts, never counted twice as goals. Transfers require two accounts. Deleted records retain their events. Referenced accounts cannot be deleted. Encrypted SQLite snapshots are atomically committed in IndexedDB. PostgreSQL contains only member password hashes, hashed device tokens, device metadata, encrypted event envelopes, server sequence numbers, and encrypted backups. Migrations run on startup.
